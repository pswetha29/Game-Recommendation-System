# 🎮 Game Recommendation System

A Machine Learning-based Game Recommendation System that recommends similar games based on the selected game.

## 🚀 Project Overview

This project uses TF-IDF Vectorization and Cosine Similarity to find games that are most similar to the game selected by the user.

The recommendation is based on:

- 🎯 Game Genres
- 💻 Platforms
- 📝 Game Description

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity
- Streamlit

## ⚙️ How It Works

1. The game dataset is loaded using Pandas.
2. Relevant features such as genres, platforms, and description are selected.
3. The text features are combined into a single feature.
4. TF-IDF converts the text data into numerical vectors.
5. Cosine Similarity calculates the similarity between games.
6. The system recommends the top 5 most similar games.
7. Streamlit provides an interactive web interface.

## 🌐 Live Application

The application is deployed using Streamlit Community Cloud.
